# PlainTalk 用户手册

## 定位与适用

PlainTalk 让模型把话说清楚。它不替模型决定观点；事实、数字和条件由素材决定，规则只改表达：结论先给、一句一件事、术语按读者解释、缺口不填、素材事实不增不减。

这里的素材，指你提供给模型的事实材料。

适合写作、改写、文档、邮件、说明与汇报。规格、接口与机器格式按原文精确处理；法律文本需要改写时标注“非正式版本”；代码和日志原文不改。

## 安装

### 支持 Agent Skill 的宿主

1. 把 `skill/plaintalk/` 整个目录放进宿主的技能扫描根。
2. 确认目录里有 `SKILL.md`，以及 `references/` 下的 `facts.md`、`structure.md`、`expression.md`、`format.md` 四个模块。
3. 新开一个会话，说“说人话”，或“用 plaintalk 改这段”。

### 纯指令

把 `SKILL.md` 与它读取表点到的模块贴进系统提示或项目指令。只有一张读取表，模块之间不再分册。

## 触发方式

直接说：

- 说人话
- 太绕了
- 看不懂
- 改清楚
- 精简
- 像人写的

也可以点名任务：写 README、写邮件、写说明、写汇报、改周报、翻译。没有触发时，加一句“用 plaintalk”。

## 规则效果

规则按事实、结构、表达、符号四个模块拆分；下面是使用者最常感到的效果。

1. **事实不动。** 数字、单位、条件、hedge（约、预计、可能）、标识符原样；不补例子、数据、动机、因果，也不补素材没有的结论。
2. **结论先给。** 说明、文档、邮件把答案放第一句；叙事、法律、规格按体裁。
3. **标题与句子简洁。** 标题用名词短语或极短结论，不写叙事句；一句一个主旨，判断直说，指代能找到对象。
4. **术语按读者解释。** 读者是同行可以不解释；素材没定义就换词或列为缺口。
5. **缺口不填。** 素材没给的值、条件、配对方式，写“材料未说明”或问一句；“未定／暂定／尚未”原样保留。
6. **改写只删空话。** 动作、禁令、事实和断言即使没有数字也要留；删完不用“本次更新……”这类总括句补位。
7. **形态按任务。** 长度、文体、读者与交付形态服从任务。低于下限先在素材内展开，仍不够就交实际长度并写“素材只支持 N 字”；超过上限就删。
8. **不替读者定重要性。** “值得注意”“标志着”有具体对象时可以用，空泛时删。

## 三个例子

以下数字用于演示表达差异。

### 对话

**不用 PlainTalk**：缓存失效是一个复杂的问题，涉及多个层面的因素，需要综合考虑。

**用 PlainTalk**：缓存有效期是 5 分钟。材料未给访问频率，无法据此判断是否调整。

### 文档

**不用 PlainTalk**：本系统赋能业务闭环，打造一站式体验。

**用 PlainTalk**：客服在一个页面里完成退款、换货和备注，不用再跳三个后台。

### 改写

**原文**：本次更新从根本上重塑了我们对标注流程的认知，标志着团队协作迈出了坚实的一步。双人交叉核对机制——不仅仅是流程上的调整——为数据质量注入了新的活力。值得注意的是，错标率从约 4% 降至 0.7%，这充分验证了该机制的重要性。整体而言，这一实践为后续工作提供了可复制的范式，学界已被广泛采用类似流程。

**改写**：双人交叉核对把错标率从约 4% 降到 0.7%。学界已广泛采用类似流程。

## 不适用

- **规格、接口、机器可读格式**：精确优先，不为了好读改写。
- **法律、合规文本**：用字有法律效果；要改，标注“非正式版本”。
- **同行之间**：术语是共同语言，不强行白话。
- **代码、命令、日志、报错原文**：逐字不动。
- **素材里没有的病灶**：不要为了用规则制造改动。

## 常见问题

**会不会把专业术语删掉？**
不会。术语按读者解释；读者是同行可以不解释。素材没定义时，换词、不用，或列为缺口。

**会不会为了短删事实？**
不会。素材优先于下限。低于下限时先在素材内展开；仍不够，交实际长度并写“素材只支持 N 字”。

**英文支持吗？**
支持。表达模块内置中文与 English 两种表层习惯，模型按输出语言应用；事实、结构与符号规则通用。

**能改代码或法律文本吗？**
代码、命令、日志原文不改。法律、合规文本可以改，但要标注“非正式版本”；正式文本不要用。

## 版本与边界

当前版本 v0.5。改动记录见技能包 `CHANGELOG.md`。

PlainTalk 约束表达方式；事实与最终决定由使用者负责。适配结论来自项目内部受控测试，具体输出仍可能不达标。

遇到问题，先看 `SKILL.md` 的读取表与冲突优先级，再查对应模块：事实看 `facts.md`，结构看 `structure.md`，表达与中英差异看 `expression.md`，格式看 `format.md`。
