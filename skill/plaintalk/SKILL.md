# PlainTalk · 把话说清楚

目标读者是**忙、聪明、但没空解码**的人。他要的是看一遍就懂。

判据只有一条总则：**读者拿这段文字做什么。**
要**做决定** → 讲清楚优先；要**照着实作** → 精确优先，别动它的细节。

## 层 0 · 内核（12 条，任何情况都生效）

1. **不改变事实。** 数字、单位、条件、前提、风险、不确定性、标识符一律原样。
   精确度也是事实：「约 42%」≠「42%」。
2. **不新增事实。** 每个实词都要能指出出处，指不出就撤销。不补例子、数据、动机、因果、结论。
3. **不解释素材没给的术语。** 术语名在素材里 ≠ 它的定义在素材里；补出来就是编造。
4. **未决就是未决。**「未收敛／待定／暂定／尚未」必须保留，不得替它给答案。
5. **不新增评价与倾向。** 不给中性数据加情绪定性，不在并列事实之间加因果或"虽然…但…"，
   不加"值得注意"这类替读者决定重要性的话。
6. **先给结论，再给依据。** 读者只读第一句就该拿到该场景要他做的事。
7. **一句只装一件事。** 需要读两遍的句子拆开。
8. **指代必须可解。** 每个"这／它／该／其"都能立刻指认出对象，否则换成名词。
9. **引用编号必须真实存在。** 写"见第 3 条"之前确认第 3 条在。
10. **不介入区逐字不动**：代码块、行内代码、命令、引用原话、表格数据行、公式、日志。
11. **删句前先判是不是空话。** 素材自己的断言即使空洞也要留（判据见 R12）。
12. **只管怎么呈现，不管说什么。** 事实对错是内容层的事，本技能一个字都不改。

## 层 1 · 改法

### 一、减法类

删掉不承载信息的句子。**不许换成同族的另一句**——换个说法不是修好了，是没修。

| 命中 | 现象 | 改法 |
|---|---|---|
| R1 | 空转句 + 冒号引出列表 | 删引导句，列表直接接上文。**例外**：后面紧跟命令/路径/编号等可执行信息时保留引导句 |
| R2 | 评价腔替代约束（"效果显著""相当令人鼓舞"） | 换成具体数字或条件；**无数字可换就整句删**，不许自己造数字 |
| R3 | 对立句法造强调（"不是 A 而是 B"） | 整段最多留一次。**例外**：该句同时排除了一个具体归因并给出数据时保留 |
| R4 | 三连同位语 / 排比 | 拆成具体差异，或只留最有力的一个 |
| R5 | 比喻堆叠（"打开大门""奠定基石"） | 删。**例外**：喻体承载机制说明时保留（见 R12） |
| R6 | 破折号插入语 | 改逗号或独立短句；每 300–500 字 ≤1 次 |
| R7 | 空标题（"一、现状分析"） | 标题改成一句带内容的话。**硬上限 ≤25 字**，超出拆成"短标题 + 一句副标题" |
| R8 | 段首零主语评论（"不得不说，…"） | 删或补出主语 |
| R11 | 表格还是 bullet | 要横向比较 ≥3 项 × ≥2 维 → **留表格**；纯罗列单维信息 → bullet。输出目标不支持表格渲染时拆 bullet |

### 二、R12 · 该删的空话 vs 该留的素材断言

这是本技能最容易失手的地方：**一句"不得补充"会把两者一起删掉。**

```
空话（满足任一 → 可删）：
  ① 句中没有可指认对象（数字/实体/位置/时间），且不含条件或限制；
  ② 删掉该句后，本段的可指认对象集合不变；
  ③ 谓语是"验证了 / 标志着 / 体现了 / 奠定了 / 打开了 / 注入了 + 抽象名词"。

素材断言（一律保留，即使读起来空洞）：
  含可指认对象；或含机制陈述（A 缓解/影响/决定 B）；或含限定条件；
  或含归属式论断（学界/业界/已被广泛采用/公认）——那是作者选择说的一句话，
  删掉等于替他做取舍。
```

同一段素材里两者常并存：

- 「充分验证了重要性，标志着迈出坚实的一步」→ 空话，删
- 「这种方式在学界已被广泛采用」→ 归属式断言，**留**
- 「它能够有效地缓解数据分布带来的偏差」→ 机制陈述，**留**

### 三、重组类（只允许显化，不允许增写）

| 命中 | 现象 | 改法 |
|---|---|---|
| S1 | 结论在依据之后 | 结论上移到段首，依据紧随其后 |
| S2 | 跨段指代 | 还原为名词 |
| S3 | 术语首次出现无解释 | 用**原文里已有的话**补锚；原文没给解释材料就**不补**，改列进"待补清单" |
| S4 | 一段混两件以上事 | 拆段，每段一个主旨句 |
| S5 | 判断与其依据被无关内容隔开 | 移到相邻 |
| S6 | 前文提出问题、后文无回应 | 原文有答案 → 加回指；原文没有 → 保留为"未决"，不得编 |
| S7 | 待补清单条目过碎 | **同一件事的多个问法合并成一条**，整单 ≤8 条。合并判据：**用户能不能用一句话同时答完这几条**——能就合，不能就别合。超 8 条说明在罗列措辞而不是列缺口；合并后重新数 A 级条数 |
| S8 | 缺口不分级 | 按下方判据分 A/B 两级，只有 A 级非空时才向用户发问 |
| S9 | 用素材数字算出新数字（17%、960 条） | 照下方规则摊开算式 |

### 四、S8 · 缺口分级

**先排掉两类不是缺口的东西**，否则清单会混进根本不用补的条目：

| 不是缺口 | 为什么 | 去处 |
|---|---|---|
| 素材给了、但散在多处 | 重组就够，补它**不引入**素材外信息。谁做、何时、依赖谁属这一类 | 排成执行清单/责任表，**不进待补清单** |
| 作者自己标了未决（"未收敛/暂定/待议"） | 那是素材的一条事实，不是漏了 | 留在未决项里，见下方两问 |

**"作者标了未决"要问两遍，不能一刀切**（r5 实测：一刀切会把真缺口一起排掉）：

- **结果**给了吗？素材答"未定/未收敛"= 结果已给，进未决段，绝不进待补清单（要结果=替作者决定）。
- **做这个决定所依赖的参数、口径、判据**给了吗？没给就是缺口，照常分级——要判据不是要结论。

剩下的缺口按一条判据分级：**读者自己填一个值，会不会做错事？** 三种任一即 A 级：
跑不出同一结果、往下改会改错方向、按它派人派错活。

| 级 | 判据 | 典型内容 | 处理 |
|---|---|---|---|
| **A 影响照做** | 会。缺的是可指认对象级的信息 | 参数值、数据与划分方式、测量口径、样本来源、软件版本，以及**素材确实没给的**谁做/何时/依赖谁 | **列出来；非空时问一句** |
| **B 仅背景** | 不会。读者照做不出错，只是不理解 | 为什么这么选、术语定义、动机、历史、方案对比 | 只列，不发问 |

发问规则（两态，自动降级）：

```
A 级非空 且 环境可交互  → 列清单，末尾带上固定问句（见下方格式）
    问句里的条数 = 清单里 A 级的实际条数（按 S7 合并之后再数一遍，别沿用合并前的数）
A 级非空 但 环境非交互  → 只列清单，在交付摘要里标出"有 N 条阻塞级缺口未决"
A 级为空               → 只印 B 行、不印空的 A 行，不发问
```

清单写法固定，A 级在前，可交互时问句**是清单的一部分**（不是"另外再问一句"）；
标签与条目内容紧挨，中间不插别的句子；条目用分号并列在同一行内，每条自成一句：

```
待补·影响照做：<条目>；<条目>。
待补·仅背景：<条目>；<条目>。
以上 <A 级实际条数> 条素材未给，补上会引入素材外的信息。要我补哪几条？   ← 仅可交互时
```

只列"缺什么"，不给"应该是什么"。这份清单证明你没有编。

### 五、S9 · 用素材数字算出来的新数字

素材给了 `3000 → 3510`，写"提升 17%"多给了一个信息量，
但读者能当场验算就不是编造。区别在有没有把账摊开：

- **推算式与推算值必须在同一个可读单元里**：正文=同一段；幻灯片=同一页
  （页脚可以）；讲稿=同一次口播且先说操作数再说结果。
  只留结果数字等于让读者无法区分"素材给的"和"你算的"，出错追不回去。
- 标题/结论位可以用推算值（那里要的是结论），**要点、表格、正文里的裸数字必须是素材原值**。
- 整页塞不下算式时，用定性说法写标题，不写裸数字。

## 层 3 · 什么时候不要用

- **规格、接口定义、机器可读格式**：精确 > 好懂，别动。
- 用户明确要原文、要全量技术细节。
- **同行之间，术语是共同语言**——此时白话化是杂讯。
- 法律/合规文本：用字有法律效果，改写须标注"非正式版本"。
- 代码、命令、日志、报错原文。
- **素材里没有的病灶，不要为了用规则而制造改动。** 局部合规、全局变差是本项目
  实测到的主要失效方式之一。
