# 密度层 · 信息密度与冗余自检

> 语言共用层。减法类（R1–R5）与 R12 管"删什么"；本文件管两个自检：信息够不够、重复多不多。
> 红线不变：不新增、不丢失（层 0 第 1、2 条）。密度变好靠作者提供事实，模型不补事实。

## 一、密度下限自检

- 指认对象 = 数字 / 实体 / 位置 / 时间 / 条件。每段写完数一遍：整段零指认对象 → 疑空段，
  按 R12 判（空话 → 删；素材断言 → 留）。
- 实测基线：数字密度每千字 AI 6.34 / 人类 17.92，时间锚点 0.69 / 1.78（docs/04）。
  这组数是诊断用，**不是生成目标**——不为凑数塞数字。
- 可移植性测试：一句话原样搬到另一个人、公司、产品上还成立 = filler。
  删，或换成本主体特有的事实、例子、机制、后果。（出处：no-ai-slop）
- 具体化：名字、数字、日期、机制 > 抽象。"提升了效率" → "部署时间从 40 分钟降到 4 分钟"。
  （出处：no-ai-slop）

## 二、冗余与节奏自检

| 命中 | 现象 | 改法 |
|---|---|---|
| D1 | 相邻句同构：连续两句主谓格局相同 | 改其中一句的结构或合并；实测倍率 2.0×（zh.md §二） |
| D2 | 顿号罗列过密：一句 ≥3 个顿号且不分层的罗列 | 拆句或改列表；横向比较 ≥3 项 × ≥2 维时走表格（R11） |
| D3 | 重复句首：连续三句同一开头词 | 改其中一句开头；刻意排比按 R4 只留最有力的一个 |
| D4 | 具体数据写回概括表述："三项指标均有提升" 替代 "延迟 −40%、错误率 −12%" | 还原原值；标题/结论位可用结论，正文与表格必须原值（见 S9） |

（出处：D1/D2/D4 lieflat-less-ai-tone；D3 blader-humanizer）

## 三、不要做的事

- 不为密度删素材断言（R12 优先于本文件一切自检）。
- 不为节奏而变化节奏：句长参差损害清晰时，以"一句一义"为准。
- 不把压缩率、TTR、PPL 当生成目标：它们是评测指标（eval/rubric.md），
  当生成目标会 incentivize 凑字与凑多样性。
