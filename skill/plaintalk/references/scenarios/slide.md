# 定向包 · PPT 单页文案

> 本场景加权层：符号/格式（bullet 与表格的选择）、信息/熵（数字精度与页脚原值）。
> 推算值规则见 SKILL.md S9。产物是大纲或单页文案文本，不生成 ppt 文件。

> 命中条件：产出是幻灯片一页——1 个标题 + 3–5 条要点。
> 台下每页停留约 40 秒。**这是全部场景里粒度最短的，容错最低。**

## 一、硬约束

| 项 | 约束 |
|---|---|
| 标题 | **说出结论**，不是主题。≤25 字。✗"效率对比" ✓"交叉核对让周交付量提升 17%" |
| 要点条数 | 3–5 条。**6 条以上说明这页该拆成两页**，不是该缩字号 |
| 每条长度 | ≤40 字 |
| 整页 | ≤180 字（不含页脚） |
| 一条一事 | 一条 bullet 一个指标或一个变化。**不要**把四个数字压进一条 |
| 对比呈现 | 旧 → 新 同位对齐（"200 → 130 条"），不要一句里绕着说 |

## 二、数字的处理规则（这个场景最容易出事）

- **默认原样照抄。** 不四舍五入、不改单位、不"约等于"。
- **要舍入必须注原值**，且注在页脚，不能只给舍入值。
  舍入本身是精度损失，不声明就是把精度当冗余删了。
- **不得引入素材里没有的比较对象或评价。**
  素材说"从 3000 提升到 3510"，不能写成"大幅提升""行业领先水平"。
- 素材给的百分比不得重算（"17%"不能变"约六分之一"）。
- 素材**没有**给百分比、只能由素材数字算出来时（见 SKILL.md 的 S9）：
  标题位可以用推算值，但**算式必须落在同一页**（页脚即可，如"17% 为推算值，3510 ÷ 3000 − 1"）；
  要点行里只许出现素材原值。

## 三、什么时候不压成 bullet

- 需要横向比较 ≥3 项 × ≥2 维 → **保留表格**（管道符表格在 markdown 渲染器里正常）。
- 单维罗列（每行一个不相干事项）→ 拆 bullet。
  判据：**读者要不要横向比较？** 要 → 表格；不要 → bullet。
- 框线字符表格（`┌─┬─┐`）在手机上会烂 → 必须拆。这是"表格一律拆 bullet"这条流行规则的
  真实适用条件，别把它扩大解释到所有表格。
