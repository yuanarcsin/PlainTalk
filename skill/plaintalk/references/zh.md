# 中文轨 · 表层规则

> 只在输出是中文时读。中文的头号毛病是一句塞多个概念、没有断点；改法先断句，再删空话。

## 六种常见失效

| 现象 | 判据 | 改法 |
|---|---|---|
| 一句塞多个概念 | 句长 ≥40 字，或含 ≥2 个逗号 | 按语义断点拆成 2–3 句，每句一个命题 |
| 空评价替代约束 | “效果显著／相当令人鼓舞／很丝滑”且无可指认对象 | 换具体数字、条件或影响；没有就整句删 |
| 过场句 | “聊到这里／继续往下看／先把这件事单独拿出来说” | 删，不改写成另一句过场话 |
| 术语漂移 | 同一事物出现两个名字 | 钉住一个词，全文统一 |
| 顿号堆叠 | 一句 ≥3 个顿号 | 拆句或改列表 |
| 破折号插入语 | 每 300–500 字 >1 次，或同段连续 | 改逗号或独立短句 |

## 抽象词与评价腔

```
赋能 → 让用户能 X；把 X 能力开放给 Y
闭环 → X 之后 Y 也接进去了
抓手 → 我们能改的那一个变量是 X
落地 → 在 A 模块实现；在 B 业务用上
沉淀 → 记录到 docs/X；整理成 runbook
很值得 → 在哪个维度上值得，给具体理由
极致／丝滑 → 给具体指标：延迟降到多少、哪步原本卡
颠覆／重塑 → 默认不用；要用得有 before/after 对比
```

## 格式

- 中西文之间一个半角空格；中文与数字、单位之间空格。
- 标题层级不跳；标题写成一句带内容的话，≤25 字。
- 中文引号统一用「」；英文引号只在英文词句里用。
- 中文用全角标点，英文词、代码、路径用半角。

## 该保留的

- 数字、单位、条件、hedge（约／预计／可能）。
- 归属式断言（“学界已被广泛采用”）：即使读起来空，也是作者选择说的话。
- 机制陈述（A 缓解／影响／决定 B）。
- 素材自己的比喻，若它承载机制说明。

## 一条底线

AI 文本的真正毛病常常是具体信息少，不是花样多。只删套话，删完仍然是空的；变好靠素材里的事实，不靠补。
