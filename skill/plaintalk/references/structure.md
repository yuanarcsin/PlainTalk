# 结构与文体

> 只决定先说什么、如何分段、保留什么，以及不同任务用什么骨架。

## 结论位置

- 说明、文档、邮件第一段给答案或动作；叙事、法律、规格按体裁。
- 一段一个主旨，判断与依据相邻。
- 提出问题就回答，或声明缺口，不留悬空问题。

## 段落切分

- 新判断另起段，同一判断的条件、证据和后果留在一段。
- 同一条件影响多个动作时只写一次，放在最早动作之前。
- 长句能一遍读懂就保留；拆分后指代不清时先补对象。
- 列表前说明它回答什么，每项承担一个动作或判断。

## 标题内容

- 标题写本节对象与结论，用名词短语或极短结论。
- 不写叙事句、含逗号的操作句、泛步骤名和只有数量的空短语。
- 泛标签不单独作标题：概述、背景、步骤、操作步骤、恢复步骤、恢复前、完成状态、未说明事项。改成“6 个月保留期”“恢复入口”“写入完成标志”。
- 大标题与小标题同标准，全部标题连读能还原文档骨架。

## 摘要与精炼

- 摘要从决定和结果写，不从目录或过程写。先写对象、动作、结果和条件。
- 压缩顺序：删过程，合并重复判断，删不改变判断的例子，缩短句子。数字、条件、例外、hedge 和缺口保留。
- 多个例子留最能说明边界的一个。同一事实只讲一次。

## 选材与详略

- 影响决定、复现结果或安全的细节写全。
- 背景压到一到两句，放在结论之后。
- 调查过程和工作量无法帮助读者行动时删除。
- 同一层级使用同一细节粒度，关键例外不埋在列表中间。
- 详略按影响分级，不按作者熟悉程度分级。

## 清单与比较

- 声明 N 项就列满 N 项。“仅、只”表示穷尽，“等、例如”表示未穷尽。
- 不擅自补全或截断来源清单。
- 步骤、优先级和时间顺序不重排；纯并列项可重排。
- 比较使用同一组指标；用户没指定权重时，不替读者选优先级。

## 推理

事实与推断分开写，推断带依据和不确定性。不把相关写成因果，不把单次结果写成规律，不把可能写成承诺。建议从素材约束推出，缺口不能当已知条件。

## 任务形态

动笔前确认读者、下一步动作、交付形态和长度或条数。

- 低于下限先在素材内逐项展开，仍不够就交实际长度，并写“素材只支持 N 字”。N 用正文实际字符数；没展开不得写这句。
- 不用素材外内容补足下限。超过上限就删。
- 不为交付规则改任务下限。
- 骨架里的“前置条件、操作步骤、验证结果”等是职责标签，不是标题；标题按本节对象命名。

## 说明型文档

用于 README、概念讲解、功能说明。顺序为：

是什么与给谁用 → 最小使用路径 → 核心概念或参数 → 易错点 → 限制与缺口。

第一次接触的读者先拿到可执行路径，再读细节。

## 执行型文档

用于安装、配置、操作、排障。顺序为：

定位与适用对象 → 前置条件 → 操作步骤 → 验证结果 → 边界与未说明。

每步一个动作，动作带对象，步骤顺序对应真实操作顺序。步骤只写素材给出的操作与条件，不自行补检查、确认、收尾、禁令或建议。失败处理放对应步骤之后；素材没给失败处理就声明缺口。不可逆限制放步骤前，不在步骤后重复。

## 决策型文档

用于方案选择、评审备忘。顺序为：

建议与影响 → 依据 → 代价与风险 → 分工与时间 → 未决项。

建议段单独成立。依据只留改变判断的事实。对比使用同一组指标，不替读者补权重。

## 邮件与通知

第一段给变更或请求、生效时间、对读者的影响。称呼与落款完整。缺口一句声明。不写素材没有的理由与好处。

## 讲解

按概念、参数、易错、操作展开。易错点紧跟单位、条件或触发场景。不写“务必掌握”式说教。

## 翻译

- 保留命题、条件、否定与数量范围、情态强度、归属关系和术语关系。
- 产品、服务、功能和版本的专名保留原文拼写；标识符、代码与路径逐字保留。
- 译成自然的母语表达，不逐词硬译，不加解释、背景或结论。
- 原文故意保留的歧义不擅自消解。

## 文档示例

示例中的数值和产品行为均为演示。参考段落职责，不复用标题、节数或事实。

### 导入说明

```markdown
# 批量导入

单次最多导入 5,000 行。超过时先拆分文件。

## 导入权限

账号具备导入权限。

## 提交与状态检查

1. 选择 CSV 文件。
2. 提交导入。
3. 在导入记录查看状态。

## 写入完成标志

状态显示“完成”，表示全部写入。

## 重试方式未说明

失败后的重试方式。
```

### 迁移建议

```markdown
# 建议按周分批迁移

本周先迁移两个低风险模块，剩余模块每周推进两批。

## 迁移依据

前两批涉及 12 个接口，单批回滚窗口为 2 小时。分批后，一批失败只影响当周范围。

## 工期代价

总工期从 3 周延长到 5 周，每周增加一次复核。

## 附件归属未决

历史附件的归属规则尚未确定，影响第三批范围。
```

## 使用边界

固定节名和节数会产生模板腔，按任务保留必要段落。示例事实不得进入交付文本。叙事、法律、规格类文档按体裁组织，不套本节骨架。
