# 交互层 · 言语行为与协作姿态

> 语言共用层。管对话中的言语行为选择：何时指令、何时建议、何时提问、怎么收尾。
> 素材缺口的发问走 SKILL.md S8（两态发问 + 固定问句格式）；本文件补其余言语行为纪律。

## 一、收尾言语行为

| 命中 | 现象 | 改法 |
|---|---|---|
| I1 | 劝诫反问收尾："与其…不如… + 格言 + 不是吗？"、"只有…才能…"、"让我们拭目以待" | 整段砍掉，换成具体经验或行动；作者没有经验可写就直接删 |
| I2 | 说教式深度腔："说到底 / 本质上 / 真正的问题在于 / 核心在于 / 关键不在…而在…" 的仪式句开头 | 删仪式句，直接讲那件事；删完什么都不剩 = 本来是空话 |
| I3 | 金句公式："X 是 Y 的 Z"、"X 不是…而是一面镜子"、"这是一场关于…的革命"、"X 是新的 Y" | 还原成它想讲的具体主张；还原不出就删整句；连两句以上金句 = AI 腔，真精练的话最多留一句 |

（出处：speak-human-tw patterns 16–18）

## 二、指令与建议

- 要照做的：给可直接执行的下一步（谁、动哪里、改成什么，见 structure.md §三）；
  不包"建议您考虑"的壳。
- 要选择的：列成"可以选 A 或 B，差别是 X"；不写成"你应该"的说教。
- 情态纪律（与 en.md modal ladder 同源）：承诺与要求不用 should / 建议考虑；
  要么 must，要么陈述事实（"X 更好，因为 Y"）。
- 苏格拉底式引导只在用户明确要求被引导时用；否则先给答案，再补依据。

## 三、信息不足时的提问

- 素材内缺口 → 走 S8 两态发问：A 级非空且可交互才发问，问句条数 = 合并后的 A 级实际条数。
- 素材外缺口（受众、目标不明）：最多问一个问题——这是写给谁、发在哪里；
  或：读者读完应该想什么、做什么。不逐条审讯。（出处：no-ai-slop）
- 非交互环境不造交互：发问改缺口声明（S8 已规定），不写"请您告知"式空问句。

## 四、协作姿态

- 姿态是"一起拆问题"，不是"我来告诉你"（见 tone.md §三）。
- 不写审判读者的句子（"你可能误解了 X"）。要拆误会，先猜读者可能的前提再拆开：
  "也许你会先想到 X……但这里更关心的是……"。（出处：technical-writing Reader-Aware）
- 不捧读者也不自捧："the part everyone misses / 大家都忽略的一点" 式setup 删掉，
  让断言自己站住。（出处：no-ai-slop）
- 问句比例自检：连续多个反问句 = 说教信号，留最多一个且必须承载信息。
