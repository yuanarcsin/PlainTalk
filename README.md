# PlainTalk

让 LLM 把话说清楚：在用户端通过上下文约束（skill / instructions / 场景包）
控制模型输出的语言风格，使其清晰易懂、逻辑通畅，且不新增、不丢失事实。

**当前版本号 v0.2**；六层基线覆盖已于 2026-10 补入技能包，版本号待推进。
技能包在 `skill/plaintalk/`（12 个文件），按需加载，无每轮注入。

## 一、要解决的问题

LLM 的输出经常"没错但不好读"：一句塞三个概念、结论藏在第四段、术语不解释、
套话比信息多、论证跳步。现有开源方案几乎全部集中在**去 AI 味**（删词汇层痕迹），
而"讲明白"需要的**信息组织与论证顺序**约束基本无人做。PlainTalk 占后者，
并把"风格"从形容词分解为六层可操作变量（见 §二）。

## 二、作用域：六层风格变量

风格不是形容词，是一组变量：调哪一层、怎么测出调没调、约束写进哪里。

| 层 | 管什么 | 规则落点举例 |
|---|---|---|
| 语气/人际 | 立场与温度：确定性、贴近度、直接性 | 不替读者抢先下判断；体裁定基调；分受众校准 |
| 组织/篇章 | 信息排列顺序与论证形状 | 结论前置、一句一义、判断与依据相邻、长文骨架 |
| 符号/格式 | 标点、间距、Markdown、缩写 | 中西文空格、冒号纪律、标题层级不跳 |
| 语言层次/语域 | 词汇难度、句法复杂度、对读者的匹配 | 分级词表、完整语法短句、情态阶梯 |
| 信息/熵 | 信息量与排列密度 | 空话判据、指认对象密度自检、信息守恒红线 |
| 语用/交互 | 言语行为选择与协作姿态 | 两态发问、反说教收尾、指令与建议之分 |

完整分解表（每层的维度、可测量指标、控制手段与证据来源）留在项目私有设计文档，
不随仓库发布；规则实现全部在技能包内。

## 三、目标与非目标

| 目标 | 非目标 |
|---|---|
| 泛化的清晰度与连贯性约束（跨场景） | 领域文体（公文/学术/营销/法律） |
| 中文优先，中英分轨 | 中英共用一套规则 |
| 纯 API 可用（不碰权重、不做微调） | 解码期干预、LoRA/SFT |
| 规则可验收（触发标记 + 改法 + 例外） | "感觉更顺了"式主观调参 |
| 多形态出口（Skill / instructions / 场景包） | 绑定单一宿主 |
| 不改变事实（信息守恒红线） | 替模型补内容、补观点 |

## 四、技能包结构

```
skill/plaintalk/
├─ SKILL.md            内核：层 0 十二条 + 层 1 改法（R1–R12 / S1–S9）+ 层 2 路由 + 层 3 不要用
├─ CHANGELOG.md        改动记录
└─ references/
   ├─ structure.md     组织/篇章：长文骨架、论证顺序、行动项完成度
   ├─ tone.md          语气/人际：基调、确定性、分受众校准
   ├─ interaction.md   语用/交互：收尾言语行为、提问、指令与建议
   ├─ density.md       信息/熵：密度下限、冗余与节奏自检
   ├─ protected.md     保护区与不介入区（改写草稿时的保真红线）
   ├─ zh.md / en.md    两轨表层规则：失效清单、格式与符号、层次与语域、防误杀
   └─ scenarios/       定向包：doc.md（技术文档）/ speech.md（讲稿）/ slide.md（PPT 单页）
```

加载方式：层 0 与层 1 随技能加载；references 命中才读、不命中不读。
规则设计纪律：每条规则同时给可定位触发标记、改法、例外；加一条规则同时想一条反例。

## 五、安装与使用

- **Agent Skill 宿主**（任何扫描技能目录的宿主）：把 `skill/plaintalk/` 整个目录放进宿主技能扫描根。
- **纯 instructions**：把 `SKILL.md` 正文贴进系统提示或项目指令；篇幅敏感时层 2 改为按需贴。
- **改写草稿**：给出草稿并说明"按 plaintalk 改清楚"，技能会自动加载 `protected.md`。
- 触发词：「说人话」「太绕了」「看不懂」「改清楚」「精简」「像人写的」。

## 六、版本

v0.2（2026-09-29）：按需加载的单段技能，无每轮注入；规则内容与 v0.1 一致
（层 0 十二条、R/S 编号未变）。改动记录见 `skill/plaintalk/CHANGELOG.md`。

带版本号是硬要求：同一条规则在不同模型上实测差一个数量级
（破折号每千字 DeepSeek 5.16 / GPT 0.11），无版本的规则半年后无人知道还对不对。
